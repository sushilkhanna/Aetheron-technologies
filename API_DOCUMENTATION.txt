1.9 REAL-TIME TRACKING & SAFETY RULES
----------------------------------------------------------------------------------------------------
- Driver STOMP Location Push: /app/live-rides/{liveRideId}/location
- Driver REST Location Push: POST /api/live-rides/{liveRideId}/location (updates Redis key live:live_ride:{liveRideId})
- Booker STOMP Location Subscribe: /topic/live-rides/{liveRideId}/location (Active during CONFIRMED state)
- After OTP Verification (VERIFIED state): STOMP broadcast to Booker STOPS. Location pings CONTINUE saving to Redis cache for Admin map and safety monitoring.
- 1km Drop Radius Auto-Completion: Driver within 1km radius of drop point for 5 minutes -> Auto-completed.
- Off-Route Warning: Driver >2km off route -> Booker receives FCM alert.
- Off-Route Auto-Completion: Driver off route for 20 minutes -> Auto-completed.
